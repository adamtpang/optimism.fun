# Fonts for generated images

Static TTF files read with `fs` by `src/app/opengraph-image.tsx`, so the link
preview card renders in the site's own type instead of a fallback font.

| File | Family, weight | License |
| --- | --- | --- |
| `Inter-Regular.ttf` | Inter 400 | SIL OFL 1.1, see `OFL-Inter.txt` |
| `Inter-SemiBold.ttf` | Inter 600 | SIL OFL 1.1, see `OFL-Inter.txt` |
| `IBMPlexMono-Medium.ttf` | IBM Plex Mono 500 | SIL OFL 1.1, see `OFL-IBMPlexMono.txt` |

Source: Google Fonts static instances (fonts.gstatic.com, Inter v20, IBM Plex
Mono v23), fetched 2026-11-23. License texts from github.com/google/fonts.
